# YamlEditor

Десктопный редактор YAML-файлов с графическим интерфейсом, на Qt 6 и C++17.
Редактируйте ключи и значения в виде дерева, фильтруйте по ключам, ищите и заменяйте
текст по документу, работайте с несколькими файлами сразу во вкладках — со светлой
и тёмной темой и локализацией на английский и русский.

## Возможности

- **Редактирование деревом** — YAML разбирается в раскрываемое дерево ключ/значение; ключи и значения правятся на месте.
- **Подсветка типов** — строки, числа, булевы значения и null разных цветов; у словарей и списков виден размер (`{3}`, `[2]`).
- **Без потерь при сохранении** — списки объектов, вложенные списки, `null`, пустые коллекции и строки в кавычках записываются как были.
- **Фильтр ключей** — скрывайте любые ключи в боковой панели, чтобы видеть только нужные поля.
- **Встроенный поиск и замена** — `Ctrl+F` / `Ctrl+H`, со счётчиком совпадений, учётом регистра и регулярными выражениями; «Заменить все» отменяется одним шагом.
- **Вкладки** — у каждого файла своя история отмены, раскрытые узлы и фильтр; несохранённые файлы помечены ●.
- **Панель файлов и drag & drop** — все YAML-файлы рабочей папки в списке; перетащите файлы или папки в окно, чтобы открыть.
- **Светлая / тёмная / системная тема** — единая палитра для всего приложения, переключается на лету.
- **Локализация** — смена языка интерфейса на лету (английский / русский), выбор запоминается.
- **Опциональная синхронизация с Яндекс.Диском** — выгрузка сохранённых файлов (см. [Опционально: Яндекс.Диск](#опционально-яндексдиск)).

## Технологии

- **Qt 6.8+** — Widgets, Network, Concurrent, Svg
- **C++17**
- **CMake** (3.5+)
- **[yaml-cpp](https://github.com/jbeder/yaml-cpp)** — подтягивается автоматически через CMake `FetchContent`

## Требования

- Компилятор C++17 (MinGW, MSVC, GCC или Clang)
- Qt 6.8 или новее с модулями Widgets, Network, Concurrent, Svg
- CMake 3.5 или новее
- Доступ в интернет при первой сборке (CMake скачивает yaml-cpp)

## Сборка

### В Qt Creator

1. Откройте `CMakeLists.txt` как проект.
2. Выберите комплект Qt 6.8+.
3. Соберите и запустите. При первой настройке CMake сам скачает yaml-cpp.

### Из командной строки

```bash
git clone https://github.com/Ruha24/YamlEditor.git
cd YamlEditor

cmake -S . -B build -DCMAKE_PREFIX_PATH=/путь/к/Qt/6.x/<компилятор>
cmake --build build

# запуск
./build/editor          # Linux
.\build\editor.exe      # Windows
```

Замените `CMAKE_PREFIX_PATH` на путь к вашей установке Qt.

## Использование

| Действие | Сочетание |
|---|---|
| Открыть файл / папку | `Ctrl+O` / `Ctrl+Shift+O` |
| Сохранить / сохранить все | `Ctrl+S` / `Ctrl+Shift+S` |
| Закрыть вкладку | `Ctrl+W` или средняя кнопка мыши |
| Отменить / повторить | `Ctrl+Z` / `Ctrl+Y` |
| Найти / заменить | `Ctrl+F` / `Ctrl+H` |
| Редактировать ячейку | двойной клик или `F2` |
| Добавить дочерний / удалить узел | `Insert` / `Delete` (или правый клик) |
| Показать лог | `` Ctrl+` `` |
| Полноэкранный режим | `F11` |

Тема и язык — в меню **Вид**.

## Локализация

В комплекте переводы на английский (`en_GB`) и русский (`ru_RU`).
Строки обёрнуты в `tr(...)`; файлы переводов хранятся в `.ts` и компилируются
в `.qm` при сборке.

Чтобы обновить или добавить переводы:

1. Запустите CMake-цель `update_translations`, чтобы собрать строки в `.ts`.
2. Отредактируйте `.ts` в **Qt Linguist**.
3. Пересоберите — `.qm` перегенерируются и встроятся в ресурсы.

## Опционально: Яндекс.Диск

Приложение может загружать изменённые файлы на Яндекс.Диск. Это необязательно —
редактор полностью работает и без этого.

Откройте **Аккаунт → Подключить Яндекс.Диск…** и вставьте OAuth-токен. В Windows
токен шифруется через DPAPI; в исходниках он не хранится. После подключения
сохранённые файлы выгружаются в `/YamlFiles` на диске, а при запуске скачиваются
более новые облачные копии (локальный файл, который новее облачного, не перезаписывается).

## Структура проекта

```
src/
├── main.cpp
├── mainwindow.*               # главное окно: меню, тулбар, вкладки, дерево, панели
├── theme/theme.*              # цветовые токены, палитра, стили, перекрашиваемые иконки
├── customWidget/
│   ├── findbar.*              # встроенная панель поиска / замены
│   ├── filelistpanel.*        # боковая панель «Файлы»
│   ├── keyfilterpanel.*       # боковая панель «Фильтр ключей»
│   ├── logpanel.*             # панель лога
│   └── connectdialog.*        # диалог токена Яндекс.Диска
├── controller/                # поиск, открытые документы, слежение за файлами
├── files/
│   ├── filesystem.*           # известные файлы
│   ├── filedownloadtask.*     # фоновая загрузка
│   ├── snapshotcommand.h      # шаг отмены
│   └── yaml/
│       ├── yamlnode.*         # дерево YAML в памяти
│       ├── yamlreader.*       # разбор / вывод через yaml-cpp
│       ├── yamltreemodel.*    # Qt-модель для дерева
│       ├── yamlitemdelegate.* # редактор ячеек и подсветка типов
│       └── yamlvalidator.*    # проверка ключей
├── security/tokenstore.*      # зашифрованное хранение токена
├── api/yandex/                # опциональная интеграция с Яндекс.Диском
├── assets/icons/              # SVG-иконки (перекрашиваются на лету)
└── translations/              # файлы .ts
```
