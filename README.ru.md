# YamlEditor

Десктопный редактор YAML-файлов с графическим интерфейсом, на Qt 6 и C++17.
Редактируйте ключи и значения в виде дерева, фильтруйте по ключам, ищите и заменяйте
текст по документу, работайте с несколькими файлами сразу во вкладках — всё в тёмной
теме с локализацией на английский и русский.

## Возможности

- **Редактирование деревом** — YAML разбирается в раскрываемое дерево ключ/значение; значения правятся на месте.
- **Чипы-фильтры ключей** — переключайте, какие ключи показывать, через чипы-флажки с переносом по ширине.
- **Поиск и замена** — поиск текста в дереве с учётом регистра и регулярными выражениями, плюс замена / заменить всё.
- **Вкладки для нескольких файлов** — открывайте один файл, несколько или целую папку `*.yml` / `*.yaml`; каждый файл в своей вкладке.
- **Drag & drop** — перетащите YAML-файлы в окно, чтобы открыть.
- **Сохранение состояния** — раскрытые узлы остаются раскрытыми при перерисовке.
- **Тёмная тема** — единый тёмно-бирюзовый стиль во всех окнах и диалогах.
- **Локализация** — смена языка интерфейса на лету (английский / русский).
- **Опциональная синхронизация с Яндекс.Диском** — загрузка изменённых файлов (см. [Опционально: Яндекс.Диск](#опционально-яндексдиск)).

## Технологии

- **Qt 6** (Qt 5 тоже поддерживается) — Widgets, Network, Concurrent
- **C++17**
- **CMake** (3.5+)
- **[yaml-cpp](https://github.com/jbeder/yaml-cpp)** — подтягивается автоматически через CMake `FetchContent`

## Требования

- Компилятор C++17 (MinGW, MSVC, GCC или Clang)
- Qt 6 (или Qt 5) с модулями Widgets, Network, Concurrent
- CMake 3.5 или новее
- Доступ в интернет при первой сборке (CMake скачивает yaml-cpp)

## Сборка

### В Qt Creator

1. Откройте `CMakeLists.txt` как проект.
2. Выберите комплект (рекомендуется Qt 6).
3. Соберите и запустите. При первой настройке CMake сам скачает yaml-cpp.

### Из командной строки

```bash
git clone https://github.com/Ruha24/YamlEditor.git
cd YamlEditor

cmake -S . -B build -DCMAKE_PREFIX_PATH=/путь/к/Qt/6.x/<компилятор>
cmake --build build

# запуск
./build/editor          # Linux
.\build\editor.exe      # Windows
```

Замените `CMAKE_PREFIX_PATH` на путь к вашей установке Qt.

## Использование

- **Open folder** — выберите папку; все `*.yml` / `*.yaml` из неё откроются вкладками.
- **Open file** — выберите один или несколько YAML-файлов.
- **Drag & drop** — перетащите файлы в окно.
- **Редактирование** — раскройте дерево и правьте значения на месте; правый клик по ключу/значению — добавить / удалить.
- **Display** — перерисовать текущее дерево из документа в памяти.
- **Save** — записать активный файл на диск.
- **Value keys** — чипами управляйте, какие ключи показаны в дереве.
- **Язык** — переключатель языка в верхней панели меняет язык интерфейса.

## Локализация

В комплекте переводы на английский (`en_GB`) и русский (`ru_RU`).
Строки обёрнуты в `tr(...)`; файлы переводов хранятся в `.ts` и компилируются
в `.qm` при сборке.

Чтобы обновить или добавить переводы:

1. Запустите CMake-цель `update_translations`, чтобы собрать строки в `.ts`.
2. Отредактируйте `.ts` в **Qt Linguist**.
3. Пересоберите — `.qm` перегенерируются и встроятся в ресурсы.

## Опционально: Яндекс.Диск

Приложение может загружать изменённые файлы на Яндекс.Диск. Это необязательно —
редактор полностью работает и без этого.

Токен доступа **не** хранится в исходниках. Укажите свой при запуске
(например, через локальный `config.ini`, который добавлен в `.gitignore`).
В репозитории есть шаблон `config.example.ini`. Никогда не коммитьте реальный токен.

## Структура проекта

```
src/
├── main.cpp
├── mainwindow.*              # главное окно: вкладки, дерево, фильтр ключей
├── editwidget.*             # диалог добавления/удаления строки
├── searchingwindow.*        # окно поиска
├── replacewindow.*          # окно замены
├── customWidget/
│   ├── customlineedit.*     # редактируемая ячейка дерева
│   └── flowlayout.*         # раскладка с переносом для чипов
├── files/
│   ├── filesystem.*         # работа с локальными файлами
│   ├── filedownloadtask.*   # фоновая задача загрузки
│   └── yaml/
│       ├── yamlnode.*       # модель дерева YAML в памяти
│       └── yamlreader.*     # разбор / вывод через yaml-cpp
├── api/yandex/              # опциональная интеграция с Яндекс.Диском
└── assets/                  # иконки и ресурсы
```
